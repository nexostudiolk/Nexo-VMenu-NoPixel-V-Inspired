# Nexo Vehicle Control Menu

**A Modern NoPixel V-Inspired Vehicle Control Menu for FiveM**

Nexo Vehicle Control Menu brings a clean, modern, and immersive vehicle control experience to your FiveM server. Inspired by the NoPixel V style, it features a stylish interface designed to complement your server's roleplay experience.

## ✨ Features

- Modern and clean user interface
- NoPixel V-inspired design
- Easy drag-and-drop installation
- Configurable settings
- Lightweight resource structure
- HTML-based interface
- Lua-powered client functionality

## 📦 Resource Structure

```text
nexo_vehicle_control/
├── html/
├── client.lua
├── config.lua
├── fxmanifest.lua
├── README.md
└── DOCS.md
```

## 📥 Installation

1. Download and extract the resource.
2. Place the `nexo_vehicle_control` folder inside your server's `resources` directory.
3. Open your `server.cfg`.
4. Add the following line:

```cfg
ensure nexo_vehicle_control
```

5. Restart your server or start the resource through txAdmin.

## ⚙️ Configuration

Open `config.lua` to review and customize the available settings.

Available options depend on the configuration provided with your version of the resource.

## 🎮 Usage

Once the resource is installed and started, use the configured menu command or interaction to access the Vehicle Control Menu.

Check `config.lua` and `client.lua` for the actual command or activation method.

## 🛠️ Requirements
